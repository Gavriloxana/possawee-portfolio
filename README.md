# Possawee Aruno — Portfolio

เว็บไซต์ Portfolio ธีมดำ–ม่วง พัฒนาด้วย HTML, CSS และ JavaScript รองรับมือถือและคอมพิวเตอร์

## แสดงผลในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ หรือใช้ `npx --yes serve .`

## เผยแพร่บน Netlify

เชื่อมต่อ repository นี้กับ Netlify เลือก branch `main` ไม่ต้องกำหนด Build command และตั้ง Publish directory เป็น `.` การตั้งค่าอยู่ใน `netlify.toml` หรืออัปโหลดไฟล์เว็บไซต์ผ่าน Netlify Drop

## เนื้อหา

อ้างอิง CV ที่เจ้าของผลงานให้มา ภาพโครงงานเป็นกราฟิกประกอบแนวคิด ไม่ใช่ภาพหน้าจอระบบจริง ไม่แสดงที่อยู่บ้านและหมายเลขโทรศัพท์ที่อ่านได้ไม่ชัดเจน วันที่ฝึกอบรมใน CV มีลำดับไม่สอดคล้องกัน จึงแสดงชื่อโครงการโดยไม่ระบุช่วงวันที่

แก้ไขเนื้อหาใน `index.html` รูปแบบใน `style.css` และการคัดลอกอีเมลใน `script.js` แบบอักษรโหลดผ่าน Google Fonts พร้อมแบบอักษรสำรองในเครื่อง
